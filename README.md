# ONEPASS DIRECT — GitHub Pages 시연 사이트

기존 웹페이지를 수정한 가상 번호판 전용 배포본입니다. 사용자가 제공한 실제 번호판 이미지는 배포 패키지에 포함하지 않습니다.

## 포함 파일
- `index.html` — 모바일 사이트
- `assets/tesla_model_y_user.png` — 사용자가 제공한 화면에서 추출한 차량 이미지
- `assets/tesla_cybertruck_user.png` — 사용자가 제공한 화면에서 추출한 차량 이미지
- `.nojekyll` — GitHub Pages 파일

## 변경점
- 차량 아래 번호판은 실제 사진이 아닌 HTML/CSS로 표시
- `00가 0001`, `00가 0002`, `00가 0003`은 실제 등록번호가 아닌 가상 예시
- 이전 번호판 이미지와 번호는 새 패키지에 포함하지 않음
- 차량별 보험 및 사고지원 정보 연동 시연 기능 유지

## 배포
1. 기존 GitHub Pages 저장소가 있다면 이 패키지의 파일로 교체한다. 특히 예전 번호판 이미지 `assets/number_plate_user.png`가 남아 있다면 저장소에서도 삭제한다.
2. GitHub Settings > Pages에서 `main` 브랜치 및 `/(root)` 배포를 확인한다.
3. 배포된 HTTPS 페이지에서 차량번호가 가상 번호로만 표시되는지 확인한다.
4. GitHub 저장소 기록에 예전 실제 번호판 이미지가 포함되어 있다면 현재 파일 삭제만으로 기록이 사라지는 것은 아니다. 공개 범위와 Git 기록 정리 필요성을 별도로 검토한다.

이 사이트는 정적 시연용이며 실제 보험정보 조회 및 사고자료 접수 서버는 없습니다.
